# recol (Recolor)

`recol` — это легковесная утилита на Go для ОС Windows, которая позволяет перекрашивать изображения (PNG, JPG/JPEG), сохраняя их градацию оттенков (яркость) и альфа-канал (прозрачность).
Отлично подходит для перекрашивания иконок, текстур и спрайтов!

## Особенности

- **Простота и легковесность:** Использует нативное окно выбора цвета Windows. Никаких тяжелых GUI-фреймворков.
- **Интеграция в проводник:** Добавляет пункт "Recolor (recol)" в контекстное меню по правому клику мыши для папок и изображений.
- **Точная замена:** Выбранные файлы заменяются на месте (оригинальные файлы перезаписываются новыми цветами).
- **Массовая обработка:** При клике по папке рекурсивно находит и перекрашивает все поддерживаемые изображения внутри.
- **Все в одном:** Установщик и логика работы находятся в одном `.exe` файле.

## Принцип работы

Алгоритм берет Оттенок (Hue) и Насыщенность (Saturation) из цвета, который вы выбрали в палитре, и применяет их к каждому пикселю изображения, сохраняя оригинальную Яркость (Lightness) и Прозрачность (Alpha).

## Установка и Удаление

1. Скомпилируйте программу (или скачайте готовый `recol.exe`).
2. Нажмите по файлу `recol.exe` правой кнопкой мыши и выберите **Запуск от имени администратора**.
3. В открывшейся консоли введите `1` для Установки (Install) или `2` для Удаления (Uninstall), и нажмите Enter.
4. При установке программа сама скопирует себя в `C:\Program Files\recol` и добавит все нужные записи в реестр Windows.

## Использование

- **Для одного файла:** Нажмите правой кнопкой мыши по файлу `.png`, `.jpg` или `.jpeg` в Проводнике Windows -> выберите **Recolor (recol)**. Откроется окно выбора цвета. Выберите цвет и нажмите OK. Изображение будет перекрашено.
- **Для папки:** Нажмите правой кнопкой мыши по папке -> выберите **Recolor (recol)**. Выберите цвет. Все изображения внутри папки и её подпапок будут перекрашены.

## Сборка из исходников

Для сборки требуется установленный Go и пакет `go-winres` (для иконок и манифеста Windows).

```sh
go install github.com/tc-hib/go-winres@latest
go-winres make
GOOS=windows go build -ldflags="-H windowsgui -s -w" -o recol.exe ./cmd/recol
```
